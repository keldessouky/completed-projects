# public/art/

Character sheets loaded over the game's own painted art at boot.

**This folder is not empty.** It holds the eight-character LPC cast built by
`npm run art:lpc` — real hand-drawn pixel art under GPL-3.0 / CC-BY-SA-3.0, not
generated by this repo. See [`LICENSES.md`](../../LICENSES.md) for the credit,
which is a licence condition and not optional.

To go back to the art the game paints for itself, delete everything here except
this file. With no `manifest.json` the loader falls straight through, and
nothing else in the codebase changes.

Full walkthrough: [Replacing the character art](../../README.md#replacing-the-character-art)

```bash
npm run art:lpc                       # rebuild this cast from LPC layers
npm run art:lpc -- hero grunt         # just these two
npm run art:check                     # verify every sheet before you reload

# or start from the game's own art and repaint it
npm run build && npm run art:export   # → art-template/, correctly sized sheets
cp art-template/hero.png art-template/manifest.json public/art/
```
