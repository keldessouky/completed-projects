# Assets

Every asset in the game is generated by a script in `tools/art`, run headless in Blender (free, open source).
Nothing is sculpted by hand or downloaded. `tools/build_all.sh` regenerates everything. `assets/generated/` is a
build output and is not committed.

```
tools/art/build.py            entry point:  Blender -b --factory-startup -P tools/art/build.py -- [--preview] [only=a,b]
tools/art/qart/geom.py        Part: primitives, lofts, sweeps, ray-cast fitting (shared with the look-dev generator)
tools/art/qart/model.py       Model: collects parts -> LOD -> baked AO -> skin weights -> .qmesh
tools/art/qart/rig.py         the shared humanoid rig, FK, two-bone IK, keyframe helpers, clip baking
tools/art/qart/preview.py     contact sheets of every clip (numpy skinning + Workbench) -> build/preview/
tools/art/characters/         characters and their clips (warrior.py)
tools/art/env/                level tiles (street.py)
tools/pack.py                 builds build/Qahira.qpk
```

## Characters

1. **Parts.** Each part is built in the bind A-pose from primitives, lofts and sweeps. Organic parts are fused with
   a voxel remesh, then smoothed.
2. **Budget.** Each part declares a triangle budget (`tris=`), and a decimate ratio is computed to hit it. The
   Warrior is about 15.5k triangles, and his maul about 1.5k.
3. **Skinning.**
   - Rigid parts (armour, lantern, belt) bind 100% to one bone.
   - Soft parts (coat, sleeves, trousers, boots, scarf) list their candidate bones. Each vertex takes a Gaussian
     falloff of its distance to each bone segment, keeping the top four weights, normalised. The result is smooth
     bends at the joints, with no hand painting.
4. **AO.** Ambient occlusion is ray-cast against the whole model (14 rays per vertex) and baked into the vertex
   colour's alpha channel.
5. **Materials.** These are per vertex: albedo (sRGB), roughness, metalness and emissive, so no textures are needed
   at game scale.

## Animation

Clips are Python functions of time that pose the rig.
- Legs and torso use forward kinematics, with rotations in the parent's bind-aligned frame.
- Weapon poses are authored as **grip positions** (a palm location, the haft direction and the head direction) in
  chest space. A two-bone IK solver works out the arms, so a two-handed maul stays in both hands through every
  clip.
- Events such as `hit` mark impact frames for gameplay.
- `rig.bake()` samples each clip at 30 fps to local translations and rotations.

`--preview` renders `build/preview/warrior_anims.png`: one row per clip, six frames each. It's the fastest way to
check a clip.

## Level tiles

`env/street.py` builds a 14 × 24 m downtown street:
- stone paving and kerbs, and slabbed pavements;
- apartment facades 3–5 floors high, with lit and dark windows, balconies with railings and laundry, AC units,
  rooftop dishes and water tanks;
- shop shutters, signboards, neon strips and awnings;
- sodium lamps, strings of festival lights, crates.

Each seed gives a different street. The JSON sidecar lists the colliders (building volumes, lamp posts, crates) and
the lights (neon, lamps, festival strings).

## Formats (little-endian)

| File | Layout |
|---|---|
| `.qpk` | `"QPK1"`, u32 version, u32 count; then per entry {u16 name length, name, u64 offset, u64 size}; then the data |
| `.qmesh` | `"QMSH"`, u32 version, u32 flags (1 = skinned), u32 vertex count, u32 index count, f32 bmin[3], f32 bmax[3]; vertices {f32 pos[3], f32 normal[3], u8 rgb+AO[4], u8 rough/metal/emit/flags[4], [u8 bones[4], u8 weights[4]]}; u32 indices |
| `.qskel` | `"QSKL"`, u32 version, u32 bone count; per bone {char name[32], i32 parent, f32 t[3], f32 r[4], f32 s[3], f32 inverse bind[16] column-major} |
| `.qanim` | `"QANM"`, u32 version, u32 clip count, u32 bone count; per clip {char name[32], f32 fps, u32 frames, u32 flags (1 = loop), u32 event count, events {char name[16], f32 time}, frames × bones × {f32 t[3], f32 r[4]}} |
| `data/tiles/*.json` | `{size: [w, l], street, lights: [{p, r, c}], colliders: [[cx, cy, hx, hy]]}` |

Fonts: Inter and Noto Sans Arabic (SIL OFL) are converted from the WOFF2 copies that ship inside Blender with
Google's `woff2_decompress`.
