## Sprites — original pixel art, generated at boot

**No third-party sprite pack is bundled.** Every sprite is authored on an integer
pixel grid by [`src/assets/pixel.ts`](src/assets/pixel.ts) (the toolkit: palette
ramps, hard 1px outlines, top-light shading, nearest-neighbour output) and
[`src/assets/sprites.ts`](src/assets/sprites.ts) (the sprites themselves), then
packed into one 2048×2048 atlas by [`src/assets/atlas.ts`](src/assets/atlas.ts).
Ground tiles come from [`src/assets/terrain.ts`](src/assets/terrain.ts).

Units are produced by a parameterised generator rather than drawn one by one, so
all twenty-odd unit sprites (five eras × king + three soldier tiers) stay
consistent with each other while changing armour, cape and weapon per era.

This art is original work by the author, covered by the project's AGPL-3.0-or-later
licence, and additionally released under **CC0-1.0**:
https://creativecommons.org/publicdomain/zero/1.0/

### Using someone else's art instead

The game supports drop-in art packs — see [`public/art/README.md`](public/art/README.md).
Put images and a `manifest.json` in `public/art/` and they override the built-in
frames at boot. That folder is gitignored on purpose: several popular itch.io
packs permit *use* but forbid *redistribution*, and keeping your copies local
means the repository never redistributes anything.

If you do bundle a pack, add its author, licence and source URL to this file, and
check the pack's terms first — "free to use" and "free to redistribute" are not
the same permission.

### Packs the project is set up for

No pack is currently bundled. If you install one, record it here. For reference,
the common itch.io pixel-art licence used by several of these packs reads:

> - You can use this asset in any game project, personal or commercial.
> - DO NOT resell or redistribute AS A GAME ASSET, it has to be part of a project.
> - Credit is not required but it is appreciated.
> - Modify to suit your needs.
> - You are NOT allowed to turn any of my assets to an NFT.

Under those terms, shipping the art inside this game is explicitly allowed — it
is part of a project, not an asset being resold. What is *not* allowed is
offering the raw files for download on their own. A public repository holding the
loose PNGs sits close enough to that line that this project keeps `public/art/`
gitignored and loads packs from disk at runtime instead. If you decide the
bundled-in-a-project reading covers your repo, un-ignore the folder and credit
the author here with a link.

## Audio — original, synthesized offline

**No third-party audio file is bundled.** All 26 cues — including the five era
weapon voices (blade, musket, rifle, machine gun, laser) and six music beds — are
synthesized by [`tools/gen-audio.mjs`](tools/gen-audio.mjs) into a single Howler
sprite. Synthesis is deterministic, so `npm run gen:audio` always produces
byte-identical output.

| Cue group | Method |
| --- | --- |
| Plucked strings (medieval beds, build chime) | Karplus–Strong |
| Drums | Pitch-swept sines + filtered noise |
| Gunfire | Noise cracks over pitch-dropping sine bodies, tightening era by era |
| Laser | Descending saw + sine with a glassy tail |
| Synth beds | Band-limited saw and square voices over the same chord walk |

The five music beds share one chord progression (A aeolian, i–VI–IV–V) and change
only instrument, tempo and drive, so the score evolves with the eras instead of
switching to unrelated tracks.

All audio is original work by the author, covered by AGPL-3.0-or-later, and
additionally released under **CC0-1.0**.
