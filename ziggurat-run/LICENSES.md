> **Note on HUD numerals.** The spec calls for tabular numerals. Rather than rely
> on a font's `tnum` feature, every in-game number is drawn from the atlas digit
> glyphs in [`src/assets/atlas.ts`](src/assets/atlas.ts), which are laid out on a
> fixed advance (`CONFIG` → `digitAdvance`). They are therefore tabular *by
> construction* — counts and coin totals cannot shift as digits change.

## Sprites and backdrops — original, generated at boot

**No third-party sprite pack is bundled.** The brief preferred CC0 sources such as
Kenney.nl and OpenGameArt; this build's network policy blocks outbound access to
those hosts (verified at build time — `kenney.nl` and `freesound.org` were
unreachable, while the npm registry and Google Fonts were), so shipping their
files was not possible. Rather than ship placeholder art or a broken download
step, every sprite is **painted procedurally with Canvas2D at boot** and packed
into a single 2048×2048 atlas.

This keeps the requirement the asset rule exists to serve — one atlas, one
palette, fully recolorable, zero runtime downloads — and it means the art has no
third-party licence attached at all.

| Asset group | Where it comes from |
| --- | --- |
| Hero, squad tiers, enemies, boss gate, lamassu, gates, projectiles, particles, UI chrome, icons, digits | [`src/assets/atlas.ts`](src/assets/atlas.ts) — Canvas2D painters, shelf-packed into one 2048×2048 atlas |
| Chapter backdrops (marsh / steppe / city), parallax strips, lane paving | [`src/assets/backdrops.ts`](src/assets/backdrops.ts) — seeded procedural Canvas2D, tiled vertically |
| Palette | [`src/config.ts`](src/config.ts) → `CONFIG.colors`, surfaced to the painters via [`src/assets/palette.ts`](src/assets/palette.ts) |

All of the above is original work by the author of this repository and is covered
by the project's AGPL-3.0 licence. Released additionally under
**CC0-1.0** for anyone who wants to reuse the art alone:
https://creativecommons.org/publicdomain/zero/1.0/

## Audio — original, synthesized offline

**No third-party audio file is bundled.** Freesound and the other suggested audio
hosts are unreachable from this build environment (same network policy as above),
so all 21 sounds — 18 SFX and 3 music cues — are **synthesized from scratch** by
[`tools/gen-audio.mjs`](tools/gen-audio.mjs) and packed into one Howler audio
sprite (`public/assets/audio.wav`, 22.05 kHz mono, ~2.3 MB).

The synthesis is deterministic (seeded PRNG), so the same command always produces
byte-identical output:

```bash
npm run gen:audio
```

| Cue group | Synthesis method |
| --- | --- |
| Lyre / harp tones (`gateGood`, `squadGain`, `upgrade`, `winJingle`, music leads) | Karplus–Strong plucked string with a softened excitation |
| Frame drums (`musicRun`, `musicTitle`) | Pitch-swept sine body + filtered-noise slap (goblet-drum *dum* / *tek*) |
| Impacts (`bossHit`, `breach`, `enemyDie`, `squadLoss`) | Pitch-dropping sines mixed with low-passed noise bursts |
| Metallic (`shieldClang`, boss armor) | Inharmonic partial stack (1 : 2.76 : 5.4 : 8.93) |
| Air (`whoosh`, `shoot`) | Noise through a sweeping filter pair |
| Stone (`lamassuWake`) | Heavily low-passed noise with a slow amplitude judder |

Music is written in a D **hijaz** maqam (D E♭ F♯ G A B♭ C) over a maqsum-style
groove — chosen to sit with the setting. Loops are rendered with tail wrap-around
so they repeat seamlessly.

All audio is original work by the author, covered by the project's AGPL-3.0
licence, and additionally released under **CC0-1.0**.

## If you want to swap in third-party assets

The seams are deliberately narrow, so replacing the generated assets with a CC0
pack (Kenney, OpenGameArt) is a contained change:

- **Sprites** — replace `GameAtlas.build()` in `src/assets/atlas.ts` with a
  `Assets.load()` of a real Pixi spritesheet. Keep the frame *names*; every call
  site refers to frames by name only.
- **Audio** — point `AudioBus.load()` in `src/core/audio.ts` at a different sprite
  file and replace `src/generated/audio-sprites.json`. Keep the cue names.

If you do, add the pack's author, licence, and source URL to this file.
