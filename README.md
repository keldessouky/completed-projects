# completed-projects
- ​Catering System ​- Pair-programmed a command-line application Developed in Java utilizing OOP principles and relying on File I/O for data management.

- ​Excelsior Venues​ - Collaborated on a venue reservation system in Java and PostgreSQL. Solution featured integration tests, a data abstraction layer, and a command line interface.

- ​Tenmo​ - ​Completed a REST-based client/server cash transfer application in Java running on Tomcat with a classmate. Used ​JDBC, ​PostgreSQL, S​ pring Boot and MVC.

- El-Lemby Platformer (اللمبي: مغامرات الحارة) - Native macOS & Windows pixel-art side-scroller inspired by the Egyptian comedy El-Lemby (2002) with Mario-style feel. Swift/SpriteKit on macOS; C#/WinForms with a custom, fully unit-tested physics sim on Windows — both sharing the same generated pixel art, chiptune audio and ASCII levels. Ships two stages — «الحارة» and «شارع السوق» — with foul-cart checkpoints, and every stage is proven completable by a bot in the test suite.

- Ziggurat Run - Mobile web game in the style of a playable ad: a Mesopotamian auto-runner with multiplier gates, squad growth and a lamassu-flanked ziggurat boss. PixiJS 8 + Howler + TypeScript, fixed 120Hz simulation decoupled from render, object-pooled hot loop, and a full front-end (12 stages, star ratings, permanent upgrades, versioned save). All sprites and all 21 sounds are generated procedurally at build/boot from code in the repo, so it ships as one static bundle with zero network requests after load. Every UI flow is proven by a headless Chromium playthrough.

- Crown & Circuit - The mobile-ad loop built for real, then carried five ages past where the ad stops. Free-roam auto-battler: your king's soldiers fight, you physically haul the dropped coins to build pads to raise towers that grow walls into a fort, and every four waves the age turns over - swords to muskets to rifles to machine guns to lasers, re-skinning units, terrain, typography and score from one era table. PixiJS 8 + TypeScript, fixed 60Hz sim with a spatial hash for 240+ live entities, polar-coordinate wall collision, and original pixel art generated at boot by a palette-ramp/outline toolkit. Ships as one self-contained HTML file; every flow proven by a headless Chromium playthrough.
- Crawler — Top-down open-world RPG: one seeded 5,120-unit world with five biomes, roads and twenty-one places, roamed with a floating joystick. Real-time combat with a spatial hash, three-state enemy AI and a leash; levels, seven attributes and gear whose every effect reads off one stat budget; a five-step quest line, a vendor, shrines, fog of war and a boss at the far end of the map. Terrain and enemy populations stream per chunk, so the world costs what one screen costs, and the save stores only what the player changed. Built on the Ziggurat Run engine (PixiJS 8 / TypeScript). All art and audio generated by code; ships as one self-contained HTML file; a headless bot plays the whole world on every build.
- QAHIRA (قاهرة) — An offline action RPG in the tradition of Path of Exile, built as a launch title for the Retroid Pocket 6 and set in Cairo and the Arab world under an eclipse that never ends. Six acts from Downtown Cairo up the Nile, across the Western Desert and the Maghreb to Iram of the Pillars; seven classes, each with its own piece of a shared passive sky and its ascendancies; crafting, uniques and a Path-of-Exile-style endgame on the Map of al-Idrisi with three pinnacle bosses; a full Arabic interface laid out right to left. A C++20 libretro core (GLES 3 tiled forward renderer, software mixer) that runs in RetroArch, with every mesh, animation, sound and pixel-art spell effect generated by scripts in the repo. Radio Kafr El-Sheikh plays the show's episodes in place of the music, and Coast to Coast AM plays from its podcast feed, downloaded by the game itself over its own TLS, and the game updates itself from the latest release. Bots play every act, class and pinnacle in CI, and an art review page marks every zone, boss and screen for the next art pass.

- Dungeon Crawler Carl: Book One (DS) — A real Nintendo DS game: a 197 KB `.nds` ROM built for the Anbernic RG DS and its two screens. First-person grid crawler on the top screen, self-drawing map and touch controls on the bottom — three floors of the Book One arc with turn-based combat, six spendable attributes per hero, loot boxes, a Bopca shop, achievements, a floor-collapse timer and sixteen-character recall codes instead of a save chip. Written in C against libnds; every sprite, glyph, floor plan and note of the PSG soundtrack is generated by code in the repo. Built without devkitPro — the toolchain is assembled from upstream sources against a stock `arm-none-eabi-gcc`. Proven two ways on every build: the portable core and renderer compile for the desktop where a map-reading bot plays the game to the end, and the actual ROM is driven headlessly in DeSmuME with assertions read out of emulated main RAM.

- Reactor — An interactive game that takes someone who has never written code to professional-level TypeScript and React: restore a dark space station one system at a time across 89 levels on ten floors, from a first `console.log` through loops, objects, async, generics, type-level programming, hooks, and production React (race conditions, debouncing, memoization, accessibility, error boundaries, testing). Inspired by *Dungeon Crawler Carl*, the repair job is broadcast live: THE FEED narrates, viewers pile in, sponsors send gifts, and a reward engine pays out constantly — crawler levels and career titles from Intern to Reactor Architect, six tiers of loot boxes, 58 achievements, 21 rankable skills, a companion pet with hats, classes with real perks, daily quests and streaks, a shop, boss HP bars, par times and collectible Codex cheat sheets. The real TypeScript 6 compiler runs in a Web Worker over a virtual file system of the standard library and React's types, so every keystroke is type-checked, hovers show inferred types, and hidden `@ts-expect-error` type tests grade your *types*, not just your output. Your code then runs in a sandbox (timers, console, loop guard) and is graded by a small testing kit that renders your components with React 19; React levels preview live. Sixteen colour profiles modelled on the best VS Code and IntelliJ themes (Dracula, Tokyo Night, Catppuccin, Darcula, SynthWave '84 with glowing code, GitHub Light…) restyle the whole game from a 🎨 button, with live hover previews; a test enforces that every profile is readable and that no two look alike. Plays on phones too: an iPhone-first touch layout (panes with Run always in reach, a row of coding keys over the keyboard, tap-for-type, swipe-to-answer arcade, bottom tabs, notch-aware), installable from Safari or Chrome as an offline web app published to GitHub Pages, and as native iPhone and Android apps (Capacitor) that CI builds, installs and plays in the iOS Simulator and an Android emulator. Runs on macOS, Windows and Linux: double-click `Reactor Quest.command`, `Reactor Quest.cmd` or `reactor-quest.sh`, or package it as a `Reactor Quest.app`, a Windows folder with a per-user installer that adds Start menu and desktop shortcuts, or a Linux folder whose installer adds a validated desktop entry; all three share one code-drawn icon (ICNS, ICO, PNG). It opens in your browser. Every level is proven both ways (the solution passes and the starter fails) in the test suite, the reward engine is unit-tested with a seeded RNG, and a headless Chrome bot solves all 79 code levels through the real UI on macOS, Windows and Linux CI, where each system's package is also installed, launched, checked and uninstalled.
